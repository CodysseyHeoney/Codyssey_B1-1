# HeoNey Portfolio

## 프로젝트 소개

반응형 웹 포트폴리오 페이지입니다.

## 기술 스택

- HTML
- CSS
- JavaScript

## 배포 주소

https://codysseyheoney.github.io/Codyssey_B1-1/

## 인터랙션 기준값

- 맨 위로 가기 버튼: 스크롤 300px 초과
- 헤더 스타일 변경: 스크롤 60px 초과
- 섹션 등장 애니메이션: 화면의 20% 진입
